Rclone for GDrive

這是個人自用的 OAuth 應用程式，只供擁有者本人透過開源工具 rclone 存取自己的 Google 雲端硬碟，用來上傳、備份與核對檔案。不提供給其他人使用。

隱私權政策

  • 本應用程式只在擁有者自己的電腦上執行，存取的是擁有者本人的 Google 雲端硬碟。
  • 不收集、不儲存、不分享任何使用者資料給第三方；沒有伺服器，也沒有分析或追蹤。
  • 授權權杖只存放在擁有者電腦上的 rclone 設定檔中。
  • 使用 Google API 取得的資料，遵守 Google API Services User Data Policy（含 Limited Use 規定）。
  • 可隨時在 Google 帳戶的第三方存取權 撤銷授權。
